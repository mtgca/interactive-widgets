Listas en Python

Colección ordenada y mutable — explora índices, slicing, comprehensions y listas anidadas

1. La lista en vivo

Agrega, elimina y modifica elementos. Los índices positivos y negativos se muestran arriba y abajo de cada celda. Puedes arrastrar las celdas para reordenarlas.

↕ arrastra una celda sobre otra para reordenar (equivale a notas.insert(j, notas.pop(i)))

>>> notas = [85, 92, 78, 95, 88]

2. Indexado y slicing

Prueba notas[i] o notas[start:stop:step] sobre la lista de arriba. Deja un campo vacío para omitirlo (equivale a None en el slice).

>>> notas[1:3]

3. Constructor de list comprehension

Arma [expr for x in iterable if cond] paso a paso y mira el resultado evaluado sobre notas.

[ for x in if ]
>>> [x for x in notas]

4. Listas anidadas como matriz

Haz clic en una celda para ver cómo se accede a ella: matriz[fila][columna].

>>> matriz[1][2]

5. De lista a mini-batches (así entrena un modelo)

En ML, un dataset suele empezar como una simple lista. Antes de cada época se baraja (random.shuffle), y el optimizador consume la lista en mini-batches (notas[i:i+batch_size]) — sin quitar nada de la lista original.
