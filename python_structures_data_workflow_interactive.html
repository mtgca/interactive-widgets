    4. Conjunto set: unicos y pertenencia

    Un set guarda elementos unicos, sin duplicados y sin orden garantizado. Es util para encontrar categorias unicas o comprobar rapido si un elemento existe.

    set no es para filas tabulares, sino para preguntas como: categorias unicas, duplicados eliminados, interseccion a & b y union a | b.

    6. Crear arrays de NumPy

    NumPy convierte listas Python en ndarray: arreglos n-dimensionales, tipados y eficientes para computo numerico.

    Definicion clave: NumPy es la biblioteca base para computo numerico en Python. Su estructura central es el ndarray: un arreglo n-dimensional, tipado y optimizado para operaciones vectorizadas, broadcasting, algebra lineal y metodos como np.mean, np.std, np.sum y np.sqrt.
