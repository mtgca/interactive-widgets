Datos disponibles

[] list

Ordenada, mutable y buena para colecciones que crecen o se transforman.


        


        

          

            
() tuple

{} dict

            
Asocia claves con valores. Es natural para representar filas con nombres de columnas.

Comparacion rapida

        

          
            

              Estructura
              Forma
              Fortaleza
              Uso en datos
            

          
          
            

              list
              Secuencia editable
              Agregar, borrar, ordenar, filtrar
              Muchas observaciones, valores de una columna, resultados de un loop
            

            

              tuple
              Secuencia fija
              Proteger una combinacion que no debe cambiar
              Coordenadas, dimensiones, pares (x, y), claves compuestas
            

            

              dict
              Claves y valores
              Nombrar cada campo y leer por significado
              Una fila de dataset, configuraciones, conteos por categoria
